Panel admin AnimeVault.

Kelola metadata wallpaper, tambahkan gambar melalui path/URL, edit detail, hapus entri, lalu ekspor katalog JSON untuk dipasang ke website.

Penting: GitHub Pages adalah hosting statis. Panel ini tidak memiliki login server dan tidak dapat mengubah website online secara langsung. Perubahan disimpan di browser perangkat ini; ekspor wallpapers.json, lalu unggah/commit ke repository untuk memperbarui galeri publik. Jangan masukkan rahasia atau token GitHub di halaman ini.

Koleksi (0)

Ekspor katalog berisi metadata dan path gambar, bukan isi file gambar itu sendiri. Simpan file gambar di folder images/ secara terpisah.

Publikasikan perubahan ke GitHub Pages

  1. Tekan Ekspor wallpapers.json di atas.
  2. Letakkan gambar yang dirujuk ke folder images/ di repository. Pastikan nama dan huruf besar-kecil path sesuai.
  3. Unggah/commit file wallpapers.json ke root repository yang sama dengan index.html.
  4. Commit perubahan, tunggu GitHub Pages selesai deploy, lalu muat ulang website.

Panel ini sengaja tidak menyimpan kata sandi atau token. Untuk pengelolaan online multi-perangkat dengan autentikasi sungguhan, diperlukan backend/CMS terpisah.
